## First, Run the Backend Java Program

You can find the instructions for running the Java program here:
`https://github.com/mvr5854/Sonic_Search`

## Run Sonic Search React App in Github Codespace

Go to the following URL and run `serve -s build` in a terminal:
`https://urban-chainsaw-7q5v5r64v5cx7x5.github.dev/`

If it can't find the `serve` command, run the following commands in the terminal:
`npm install -g serve`
`serve -s build`

## Run Sonic Search React App in Local Machine

Run the following command to clone the project in your local machine, install the necessary packages, and run the React app:
`git clone https://github.com/mvr5854/Sonic_Search_UI.git`
`npm install`
`npm run start`

**Note: If you run the React App in local machine, you need to run the Java program in local machine!**
